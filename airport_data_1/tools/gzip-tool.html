前端 GZIP 压缩工具

将 JS（或任意文本）文件压缩为 *.js.gz.js（内嵌 base64 的 gzip 数据），配合 gzip-loader.js 在页面中解压执行。
走普通 <script> 加载：file:// 与 http(s) 均可用，无需服务器配置，比原文件小得多。
当前浏览器不支持 CompressionStream（需 Chrome/Edge 80+、Firefox 113+、Safari 16.4+），请换用 tools/compress-gz.ps1 脚本压缩。
点击选择 或 拖拽文件到此处 支持 .js / .json / .css / .txt 等任意文本文件
全局变量名： 同一页面压缩多个文件时请使用不同变量名

页面中的使用方法（生成后把 xxx.js.gz.js 和 gzip-loader.js 放入项目）：
<script src="js/gzip-loader.js"></script>
<script src="js/xxx.js.gz.js"></script>
<script>
    // 解压并按全局作用域执行原 js（同步，等效于 <script src="js/xxx.js">）
    GzipLoader.exec(window.__GZ_B64__);

    // 之后的代码即可使用原 js 中定义的全局变量/函数
</script>
